## Key Metrics Explained

### Kinetic Energy (K)
**Formula**: K = entropy_rate × interaction_degree × bandwidth_utilization

**Meaning**: Information dissipation rate at system boundary
- High K: Skill is currently active, in heavy use, dissipating
- Low K: Skill is dormant, latent, storing energy
- **Use**: Identify currently stressed skills needing load balancing

### Potential Energy (V)
**Formula**: V = schema_complexity × representational_depth

**Meaning**: Stored representational capacity in schema
- High V: Rich, diverse schema enabling many future computations
- Low V: Specialized, simple schema with limited adaptability
- **Use**: Identify skills with high future capability

### Hamiltonian (H = K + V)
**Property**: H is conserved along skill trajectories (dH/dt = 0)

**Meaning**: Total information energy stays constant as K ↔ V oscillates
- **Use**: Validate energy system consistency (|H - (K+V)| < tolerance)

### Energy Density
**Formula**: density = K / storage_footprint

**Meaning**: Efficiency metric (bits/byte/second)
- **Use**: Priority ranking for deployment (high density = deploy first)

### Oscillation Period
**Formula**: T_period = 2π / √(reaction_rate)

**Meaning**: How fast skill switches between latent and active modes
- ~19.3 sec: High coupling (responsive to load)
- ~19.9 sec: Low coupling (sluggish response)
- **Use**: Predict skill latency and throughput windows

"""
Random walk through skill space using energy gradient and ACSet morphisms
"""
function gay_skill_walk(start_skill::String, steps::Int=1000, seed::Int=0x42d)
    """
    Walk through skill space:
    - Probability of moving to neighbor proportional to energy density
    - Each step assigns deterministic color via Gay.jl seed
    - Trajectory reveals skill clusters and energy landscape
    """

    # Find starting skill in energy data
    start_idx = findfirst(s -> s["name"] == start_skill, energies_data)
    if isnothing(start_idx)
        error("Skill not found: $start_skill")
    end

    current = start_idx
    trajectory = [energies_data[current]["name"]]
    colors = []

    # Walk through skill space
    for step in 1:steps
        current_energy = energies_data[current]
        current_density = current_energy["density"]

        # Find neighbors (all other skills)
        neighbors = collect(1:length(energies_data))
        deleteat!(neighbors, current)

        # Probability proportional to energy difference (gradient)
        neighbor_densities = [energies_data[n]["density"] for n in neighbors]
        energy_diffs = abs.(neighbor_densities .- current_density) .+ 1e-10

        # Weights: more likely to move toward higher density
        weights = 1.0 ./ energy_diffs
        weights ./= sum(weights)

        # Sample next skill
        next_idx = neighbors[sample(1:length(neighbors), Weights(weights))]

        # Deterministic color from Gay.jl seed + step
        step_seed = seed + step
        color = gay_color_at(step_seed)

        push!(trajectory, energies_data[next_idx]["name"])
        push!(colors, color)

        current = next_idx
    end

    return trajectory, colors
end

"""
Gay.jl provides deterministic color generation via SplitMix64 RNG.
Each seed → deterministic sequence of colors (no true randomness).

This enables:
- Reproducible walks (same seed = same colors)
- Verifiable exploration (colors are provenance/proof)
- Parallel walks (different seeds = independent color streams)
- Distributed computation (each worker gets unique seed range)
"""

function demonstrate_gay_determinism()
    println("Gay.jl Determinism Example:")
    println("=" * 60)

    # Same seed → same color
    seed1 = 0x42d
    color1_a = gay_color_at(seed1 + 1)
    color1_b = gay_color_at(seed1 + 1)
    println("Seed 0x42d + 1:")
    println("  Color A: $color1_a")
    println("  Color B: $color1_b")
    println("  Same?   $(color1_a == color1_b) ✓")

    println()

    # Different seed → different color
    seed2 = 0x43d
    color2 = gay_color_at(seed2 + 1)
    println("Seed 0x43d + 1:")
    println("  Color:  $color2")
    println("  Different from seed 0x42d? $(color2 != color1_a) ✓")

    println()
    println("This determinism enables:")
    println("- Reproducible skill walks")
    println("- Verifiable color assignment")
    println("- Parallel exploration with independent streams")
end

demonstrate_gay_determinism()
